# Optional local demo examples

To enable the one-tap examples, add two WAV clips you have permission to use:

- `genuine.wav` — a genuine speech sample
- `synthetic.wav` — a synthetic speech sample

Keep each clip between 2 and 10 seconds. These examples stay on your machine and are excluded from version control. The displayed example type describes the sample you supplied; it is not the detector's result. Without a trained local model, analysis still returns an explicitly marked inconclusive demo response.
